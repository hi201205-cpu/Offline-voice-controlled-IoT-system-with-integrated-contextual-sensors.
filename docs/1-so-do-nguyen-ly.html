Hình 1. Sơ đồ khối nguyên lý kết nối các thành phần ngoại vi với vi điều khiển ESP32-S3
Phân bổ nhiệm vụ Dual-Core của ESP32-S3:
  • Core 1 (Application Core): Thực thi vòng lặp chính loop(), thu âm I2S qua DMA, phát hiện giọng nói VAD, chạy mô hình học máy TinyML KWS (Edge Impulse), quét ma trận phím bảo mật, xử lý luật tự động hóa và điều khiển Relay/Servo.
  • Core 0 (Network Core): Chạy FreeRTOS task firebase_task phụ trách duy trì kết nối WiFi STA, lắng nghe luồng sự kiện realtime SSL Stream (/commands), nhận diện đồng bộ dữ liệu cảm biến và trạng thái thiết bị lên Firebase RTDB.
